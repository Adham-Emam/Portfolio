# Portfolio Website

## Description

This is my personal portfolio website showcasing my projects, skills, and professional experience. It serves as an interactive resume to highlight my work and connect with potential employers or collaborators. The website is designed to be responsive, accessible, and user-friendly.

## Tools & Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Frameworks/Libraries:** React, Next, Tailwind CSS
- **Hosting Platform:** GitHub, Vercel
- **Version Control:** Git & GitHub

## Live Link

🔗 [https://adhamemam.vercel.app]

## How to Run the Project Locally (If Applicable)

1. **Clone the repository:**
   ```sh
   git clone https://github.com/Adham-Emam/Portfolio.git
   ```
2. **Navigate to the project folder:**
   ```sh
   cd portfolio
   ```
3. **Open the project:**
   - run:
     ```sh
     npm install && npm start
     ```
4. **Access locally:**  
   The website should open in your default browser at `http://localhost:3000` (or similar).
